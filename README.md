# 今日头条评论 VOC 分析原型

基于 1994 条今日头条 App Store 公开评论构建的客户之声(VOC)分析原型。

**在线访问 → https://k4ming-leung.github.io/toutiao-voc/**

| 页面 | 内容 |
|---|---|
| [分析原型](https://k4ming-leung.github.io/toutiao-voc/) | 总览 / 问题热榜 / 原声流 / 趋势与版本 / 频道健康度 / 风险雷达 / 简报与处置 / 方法论 |
| [处置方案](https://k4ming-leung.github.io/toutiao-voc/response-plan.html) | 按优先级排序的处置分级、触发数字与责任方 |

这份原型的重点不是「跑出了什么结论」,而是**分析过程中三次被数据证伪的经历** ——
「负面率翻倍」其实是抽样切换,「某问题环比 +19000%」是口径问题,「版本劣化 16 倍」是样本量不足。
三条各自怎么被推翻,页面里逐条写了。
